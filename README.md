# Electricity Bill Calculator in C

## Description
This program calculates an electricity bill based on the number of units consumed using conditional statements and sample tariff slabs.

## Concepts Used
- `if`, `else if`, and `else`
- User input using `scanf()`
- Arithmetic operations
- Conditional statements

## How to Run
```bash
gcc electricity_bill.c -o electricity_bill.exe
./electricity_bill.exe
```

## Language
C

## Note
The tariff rates used are examples for practice. Replace them with the rates specified in your question if they differ.
